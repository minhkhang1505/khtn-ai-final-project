🚀 RUN THE APP

Terminal:
  flutter run

What happens:
  1. Splash screen (2s)
  2. MainPage opens
  3. Chat tab selected by default
  4. Tap tabs to switch

🎨 CUSTOMIZATION CHEAT SHEET

Change Tab Order:
  Edit _pages list in main_page.dart

Change Tab Icons:
  Edit BottomNavigationBarItem icon/activeIcon

Change Colors:
  selectedItemColor: Colors.yourColor

Add New Tab:
  1. Create page widget
  2. Import in main_page.dart
  3. Add to _pages list
  4. Add BottomNavigationBarItem

💡 QUICK CODE SNIPPETS

Navigate to Main:
  NavigationService.navigateTo(AppRoutes.main);

Show Success:
  NavigationService.showSuccess('Done!');

Open Settings:
  NavigationService.navigateTo(AppRoutes.settings);

Logout:
  NavigationService.navigateToAndRemoveUntil(AppRoutes.login);
